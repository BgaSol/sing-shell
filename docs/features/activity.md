# 活动与诊断

活动页展示当前会话、上下行速率/累计量、当前及近期已观测连接。每项提供目标、协议、出口、命中规则、字节与开始时间，展开后查看进程等已知字段。未知字段显示未知或不可用，不从域名反推应用身份或匹配结果。

当前实际连接启用“绕过 TUN”时，活动页明确提示：这部分流量不经过核心，不计入此处连接与流量统计。提示依据 worker 已确认的运行状态，保存草稿或失败候选不会提前改变它，不新增系统旁路采集。

受控 worker 探测官方核心 with_clash_api 能力，生成仅绑定 127.0.0.1 的随机端口和高熵 secret。采集客户端只 GET 固定 /connections，禁用系统代理及重定向；端口和密钥不回传 WebView，不开放外部面板或放宽 CSP。核心没有该能力时仍可连接，活动明细明确不可用。原始配置不被改写以注入监控接口。

每秒有界 HTTP 采样，限 4 MiB 和 2 秒。核心已命中的 policy tag 对应当前运行清单，final 对应默认规则；未知格式保留原描述，不自行重做流量匹配。第一次采样、计数回退、换会话或断采不伪造速率。采集故障与网络运行状态独立，不为了展示错误重启 TUN。

最多缓存 1,000 条活动连接及 1,000 条近期结束连接；只有完整成功采样中消失的已观测连接才标结束，断采/截断不批量判结束。短于采样间隔的连接可能遗漏，结束原因和最终字节可能未知，不能当作完整网络审计。

前端按会话与游标读每页最多 100 条，离开页面或隐藏窗口停止页面读取，迟到结果丢弃。连接详情原位展开，轮询保持展开状态。结构化会话事件来自明确的壳用例结果，原始日志通过诊断入口查看，全部按文本展示。

事件/日志各有单调序号及 1,000 条内存上限，日志分页同时限制编码字节，避免展示请求突破授权消息边界。切换不丢失已登记的凭据脱敏；控制密钥也在启动前登记脱敏。日志不自动上传或写入历史数据库，核心自己的文件日志仍由其配置决定。

## Fake-IP 展示边界

目标优先显示官方核心还原的 host；规则继续根据核心已命中的 tag 归因。虚拟地址不被当成网站真实出口，API 未提供实际拨号 IP 时不推测 IPv4/IPv6。活动接口可选，关闭或不可用不影响 Fake-IP 缓存。

# 节点管理

节点是独立连接参数，分流是全局设置。每次只运行一个所选节点。页面提供模态导入、预览、确认、播放连接、名称/标签编辑和删除，不要求编辑 sing-box 配置。

## 导入边界

支持多行分享链接、UTF-8 TXT、本地 sing-box JSON / JSONC 的独立 outbound。文件必须是有效 UTF-8，非法字节不会被替换后导入。JSONC 通过核心格式化到私有临时材料，不改原文件。先预览每项结果，再一次提交有效且未重复的节点；无效项说明原因，链接行号保留原始空行，未知选项不静默丢弃。

预览在后端只保留一份、10 分钟有效。新预览被接纳后立即使旧票据失效，即使新预览整体失败；取消、过期或退出销毁待提交材料。提交核对修订，成功后消费票据；修订冲突或写入失败不改变有效设置，当前票据在未过期、未取消时可重试。前端文件读取或预览失败后必须重新预览才能提交。

| 协议 | 支持范围 |
| --- | --- |
| Shadowsocks | SIP002 / Base64；AEAD 与 2022 加密；不支持插件 |
| Trojan | TCP、WebSocket、gRPC，TLS |
| VLESS | TCP、WebSocket、gRPC，TLS / Reality，Vision flow |
| VMess | 常见 Base64 JSON，TCP、WebSocket、gRPC，TLS |
| Hysteria 2 | TLS、salamander 混淆 |
| TUIC | UUID/密码、TLS、受支持的拥塞控制与 UDP relay |

TLS 支持 SNI、ALPN、显式 insecure、有限 uTLS 指纹和 Reality。协议参数最终由官方核心检查。依赖其他 outbound 的 detour、selector/urltest、插件、未知传输和未识别字段拒绝导入；可用原始配置模式运行完整配置。JSON 导入不采用其 DNS、路由或监听设置。

VLESS 分享链接接受缺省或显式 `encryption=none`，两者生成相同节点并参与去重；空值或其他加密声明拒绝。该字段不写入 sing-box 节点 JSON。WebSocket 的 `host` 只设置 HTTP Host，TLS 的 `sni` 单独设置服务器名称；未给出 SNI 时由核心处理默认值，壳不根据 Host 猜测或关闭证书校验。

链接查询键值只进行一次严格百分号和 UTF-8 解码，查询中的原始 `+` 为空格，字面加号使用 `%2B`。非法编码、重复的解码后参数名、行内原始控制字符和未知参数拒绝导入；不自动修复 `vless\://` 等转义文本。`insecure` 与 `allowInsecure` 都必须是 `0/1/false/true`，同时出现时必须逻辑一致。错误不回显链接、未知参数名或参数值。

单批最多 2 MiB、链接最多 16 KiB、每批最多 500 节点、总计最多 2,000 节点。按规范化参数去重，重名允许，ID 独立。仅重命名不改变运行参数。

## 标签与连接

每节点最多 20 个标签，每标签最多 32 字符；没有标签时显示“默认”。标签筛选和搜索只读取公开名称、地址、协议与标签，不搜索凭据。列表每批显示 100 个节点。

每行播放按钮直接连接该节点；运行中点击其他节点请求切换，当前运行节点的按钮执行断开。实际运行节点与正在准备的目标分开显示。导入不自动连接，名称和标签变更不重连或产生待应用。

连接使用已保存的规则。未保存草稿保留，不能隐式进入连接配置。worker 在同一授权会话准备候选并校验，成功后才停旧、清理、起新；准备失败保留旧连接。新连接启动失败且清理完成时最多恢复一次旧固定连接；停止/退出优先，不形成崩溃重连。

运行或清理期间不能删除节点或切换模式。删除恢复节点撤销其恢复依据。原始配置模式下节点播放不可用，停止后在高级设置明确切回节点模式。

## 数据保护

凭据只存本机私有设置及运行配置，不回传前端快照。预览只含名称、协议和地址摘要。schema 5 不读取旧代结构；原件保留，显式备份并初始化后重新导入。写入失败不覆盖有效设置。Unix 使用 0700 / 0600；Windows 限当前用户与 SYSTEM，授权目录限管理员与 SYSTEM。

生成配置和导入临时材料在结束时清理。本地保存并非加密保险库。日志有界并屏蔽已知凭据，仍可能包含地址等敏感内容，分享前需检查。

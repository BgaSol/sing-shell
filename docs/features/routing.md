# 分流

新安装默认代理：未命中规则的流量使用当前节点。可改为默认直连，始终只提供代理、直连两种出口。保存改变下次期望设置，运行连接需“应用并重启”或停止后启动才生效。

## 固定优先级

1. 本机和局域网固定直连。
2. 自定义精确域名。
3. 包含子域名规则，较长域名优先。
4. 自定义 IP / CIDR，较长前缀优先。
5. 站点集合的直连规则。
6. 站点集合的代理规则。
7. 默认动作。

域名不带 URL、路径、端口或通配符；可勾选包含子域名。IP 接受 IPv4、IPv6 或 CIDR，保存时规范化网段。相同匹配条件不能重复，基础私网不能被自定义代理网段覆盖。最多 1,000 条自定义规则。

域名由 sing-box DNS 与嗅探获得，纯 IP 连接不能保证还原域名。生成配置使用真实 IP、嗅探、DNS 劫持和解析阶段，壳内不另写流量匹配器。本地解析用于直连及节点主机名，代理 DNS 使用经节点的 Cloudflare HTTPS；域名及站点选择同时用于 DNS 服务器选择。IPv4 和 IPv6 都纳入 TUN。浏览器自己的 DoH、加密嗅探不可见的域名及其他 VPN 冲突不保证能按域名识别。

## macOS 系统 DNS

节点模式连接时，按需授权 worker 在 SystemConfiguration 登记独立随机键的临时默认解析器，指向隧道 DNS，不修改 Wi-Fi／以太网的持久 DNS 偏好，无需用户设置。登记后核对有效系统解析器、刷新缓存，再确认连接。核心仍负责 DNS 解析和分流。

节点主机名及直连 DNS 使用官方核心的物理接口 scoped 上游；接管前后必须存在独立入口，避免回退到自身隧道。IPv6 链路本地 DNS 保留接口作用域。运行中低频复核，切网后不能确认入口或接管失效就清理并提示重新连接，不自动重连或争抢其他 VPN 的优先级。

断开、取消或核心退出统一释放本次临时解析器并刷新缓存。worker 被强杀时由系统会话回收临时键，核心残留另按受保护记录处理；不扫描删除其他应用的 DNS 键。更具体的系统域名范围、`.local` 和搜索域仍服从 macOS 行为；普通私有域名遵循现有 DNS 分流规则。原始配置与外部核心不使用壳的 DNS 接管。

# 图标与界面

Sing Shell 使用粉底、黄贝壳和薄荷绿底座的应用标识，沿用 SoDeck 的多巴胺配色。页面固定为浅色，不随系统深色偏好切换配色。

## 可验收行为

- 窗口内容中的品牌标识、网页图标和各平台打包图标均来自 `assets/icon.svg` 中的贝壳原稿。
- 页面使用暖奶油背景 `#fbf1e8`、淡黄面板 `#fffbe6` 和墨黑文字及结构边框 `#20211f`。
- 主操作使用明黄 `#ffde75`，导航选中使用粉色 `#ffb7cf`，键盘焦点和原生复选框使用紫色 `#5346a6`。
- 运行状态使用薄荷绿底，失败使用桃粉底，并保留状态文字和错误说明；不只依靠颜色表达状态。
- 导航、区域标题和主要运行操作使用统一的线性 SVG 图标。图标不替代文字标签，不向读屏器重复播报。
- 禁用、悬停、按下和键盘焦点均有可见反馈；日志保持等宽字体、按文本展示和原有滚动行为。
- 在默认 960 × 720 窗口和最小 620 × 560 窗口内，运行页、更新页、展开的高级选项及网络设置不产生页面横向溢出；竖向内容允许滚动。

## 维护

颜色角色集中在 `src/style.css`。品牌 SVG 同时由前端构建引用，修改后执行 `npx tauri icon assets/icon.svg`，同步生成并提交 `src-tauri/icons/` 中已有的 PNG、ICO 和 ICNS 资源。

图标生成不等于各平台原生安装包验收。Windows、macOS 和 Linux 的实际显示仍以对应原生运行器的构建与运行结果为准。

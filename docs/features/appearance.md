# 图标与界面

Sing Shell 固定使用 SoDeck 多巴胺浅色视觉。贝壳标识来自 assets/icon.svg，托盘继续使用提炼后的贝壳状态图标与 macOS 单色模板。

## 可验收行为

- 背景 #fbf1e8、淡黄表面 #fffbe6、近白输入 #fffef5、正文与深色描边 #20211f。
- 当前导航和弹窗头使用粉色 #ffb7cf，主操作使用明黄 #ffde75；焦点和链接为紫色 #5346a6，运行采用浅薄荷底，错误采用桃粉底，并保留文字。
- 所有页面、弹窗和标题栏共享文本框、多行输入、下拉、单选、开关、复选框、按钮的统一规范。分流没有独立配色或通用控件覆盖。
- 自绘顶部栏整合连接状态和控制；Windows/Linux 使用应用窗口按钮，macOS 保留原生交通灯。关闭仍走收起链路，退出走资源清理协调器。
- 节点、分流、活动、设置为四个入口；设置只有常规、更新、高级三个页内分类，没有侧栏二级树。
- 统一线性 SVG、系统字体、深色描边和紧凑列表；禁用、悬停、按下、键盘焦点和字段错误均清楚可辨。
- 默认 960×720、最小 620×560 与系统缩放下操作可达，无整页横向溢出；弹窗固定头尾并独立滚动。
- 日志、核心输出与导入错误始终按文本展示；字段和列表名称支持长内容，颜色不单独承担状态含义。

## 维护

视觉规则见 DESIGN.md；全局颜色与控件在 src/style.css，分流布局在 src/routing.css。图标修改执行 npx tauri icon assets/icon.svg，同步提交既有平台资源；托盘资源执行 node scripts/tray-assets.mjs。图标生成和浏览器预览不代替各平台实际包与原生窗口验收。

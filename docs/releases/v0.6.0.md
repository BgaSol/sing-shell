# Sing Shell v0.6.0

本次重构节点、分流、活动和设置。节点支持标签筛选和逐行直接连接；自定义策略可同时包含多个域名与 IP，按用户顺序首次匹配，唯一默认规则兜底。固定开源来源支持手动/自动更新，准备的新内容在重连后采用。活动页展示结构化连接、核心命中规则和会话事件；设置采用四个二级分类，导入与编辑使用紧凑模态框。

**数据格式变更：** 本版不迁移旧代设置，原件保留并阻止自动恢复；用户需显式“备份并重新初始化”后重新导入节点/规则。原始配置文件和外部核心文件不会删除或覆盖。

## 边界

继续保持单节点、默认 TUN、按需短期授权 worker、原始配置和外部核心；不增加节点订阅、测速、策略组、系统代理开关或崩溃重连。活动为每秒有界采样，短连接可能遗漏，不能作为完整网络审计。

Windows 未做发行商代码签名，macOS 为 ad-hoc 签名、未公证。交互式 UAC/polkit/macOS 管理员授权、真实注销登录、休眠、物理切网及托盘视觉未在本轮实际执行；原生报告单独记录登录项系统审批与托盘宿主的实际状态。

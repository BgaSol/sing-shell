# Sing Shell v0.1.0

首次正式版，提供本地 sing-box 核心选择、JSON / JSONC 配置导入与校验、启动/停止、状态和有界运行日志。启动前重新校验，关闭应用时结束受管核心；核心由用户自行获取，不包含在壳的安装包中。

## 实际验证

五个目标均在对应原生运行器编译、测试、打包和验收；ARM64 包内程序核对原生机器码格式及架构，未使用 x86_64 模拟产物。

| 目标 | 包 | 实际验收 |
| --- | --- | --- |
| Windows x86_64 | NSIS | 临时目录安装、安装后程序启动、WebView / IPC、退出及卸载 |
| Windows ARM64 | NSIS | 同上，原生 ARM64 |
| Linux x86_64 | DEB / AppImage | DEB 解包程序与 AppImage 均完成 WebView / IPC、启动和退出 |
| Linux ARM64 | DEB / AppImage | 同上，原生 ARM64 |
| macOS ARM64 | DMG / app.tar.gz | DMG 挂载及 app 归档解包后程序均完成 WebView / IPC、启动和退出 |

每个平台另使用已核验上游归档摘要的官方 sing-box **1.14.4** 通过配置检查、核心启动、SOCKS5 回环 TCP 双向转发、停止及端口释放测试。测试核心不进入发行附件。

类型、格式、文档链接和工作流命令检查、7 项核心生命周期测试、原生二进制架构检查回归测试均通过。

## 限制和跳过范围

- Windows 包未做发行商代码签名；macOS 使用 ad-hoc 签名，未公证。未验收互联网下载后的 SmartScreen / Gatekeeper 交互。
- 不提供订阅、节点管理、系统代理开关、TUN 权限提升、托盘、后台服务或自动更新。未进行相应专项测试。
- 停止使用进程组终止，不承诺核心缓存平滑落盘；Unix 应用被 SIGKILL 等强制终止时不能保证核心回收。
- 实际转发测试使用本机回环直连，不代表远程节点可用性、所有 sing-box 配置和协议组合均已验收。完整用户行为见[核心与配置](../features/core.md)。

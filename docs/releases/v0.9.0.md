# Sing Shell v0.9.0

托盘现在可以选择已导入的服务器，再明确连接或切换。选择服务器不改变当前连接；运行 A 时选择 B，会同时显示实际连接 A 和切换到 B 的操作。连接失败保留选择，断开始终结束当前会话，查看原因才打开主窗口。

节点页区分已选择、使用中和正在连接。选择服务器不再误触发设置待应用；对当前连接应用已保存设置时保持实际节点，也保留另外选择的服务器。原始配置、短期系统授权、一次失败回退和退出清理沿用既有边界，不新增依赖或更改数据格式。

## 验证与限制

固定原包源码 `7421b9df123e74ae7943ca88fcb63acaac1e0a05`。[五原生 Check](https://github.com/BgaSol/sing-shell/actions/runs/45997344293)、[五原生网络验收](https://github.com/BgaSol/sing-shell/actions/runs/45997358428)及[签名包构建与独立验收](https://github.com/BgaSol/sing-shell/actions/runs/45997369723)全部通过；包验收第二次仅复验失败平台，使用第一次构建的相同字节。主分支同源码的 Check 与网络验收也通过，ARM64 使用原生运行器。

发布前已下载草稿全部 16 个附件，核对大小与 SHA-256，均与已验收原包一致；五目标更新清单的下载 URL、大小、摘要和 Tauri 签名逐项匹配。正式发布继续使用这些原始文件，不重新打包。

正式发布后再次匿名 HTTPS 下载全部 16 个附件，完整文件的大小和 SHA-256 均与草稿及验收原包一致；公开 Latest 和标签源码已确认。大附件首次整文件下载超时后改用分段续传，最终仍核对完整文件摘要，未跳过任何附件。

五个平台的实际包均完成启动退出、官方签名升级、设置保留，以及官方 sing-box 1.14.4 和 1.14.5 的真实 TUN、双栈加密转发与退出清理。Windows 覆盖两种安装范围，Linux 覆盖 DEB 和 AppImage，macOS 覆盖 DMG 与 app 归档。v0.5.4/v0.6.0 升级后的设置保留与核心恢复、本版到隔离高版本候选的实际更新均通过。

新增自动化覆盖选择持久化、失败保存、修订冲突、恢复依据隔离和托盘状态；实际应用 smoke 检查 2,000 个原生菜单项、勾选、重命名和模式更新。真实网络回归检查选择不打断旧连接、应用设置不顺带切换所选节点。

Windows ARM64 托管运行器虽然有 Explorer 和任务栏，但独立窗口直接调用 Shell_NotifyIconW 注册和更新均返回 E_FAIL；与 Tauri 和服务器选择无关。该目标实际通过原生 2,000 项菜单、改选、改名和模式检查，以及保留可见主窗口的故障回退；任务栏图标和交互没有验到。其他四个平台完成应用托盘检查。独立探针、错误码及每次 smoke 记录保留在包验证证据中，不能把菜单通过解释为 ARM64 任务栏交互通过。

首次包验收的 Windows ARM64 网络夹具准备阶段遇到随机回环端口 `49840` 绑定 EACCES，保留失败报告后以同原包复验通过。此前 Linux ARM64 两次系统域名查询出现 ENOTFOUND，均在 TUN 和双栈转发成功后发生；最终源码完整矩阵通过，原断言未放宽。macOS 菜单读回测试曾把 AppKit 显示标题与带助记转义的输入比较，已按平台契约修正。旧草稿及未满足实际菜单证据的中间包均未发布。

本地 Windows 类型/格式、20 项脚本、140 项默认 Rust 回归、生产 NSIS 构建和应用 smoke 通过；官方核心配置、路由、SOCKS5、Fake-IP/TLS 和缓存专项另行通过。没有新增生产依赖，npm/Cargo 锁文件不变。完整摘要、原始运行、失败报告和跳过范围见本版包验证与网络验证 JSON。

原生菜单展开中的鼠标、键盘、滚动、交互 UAC/polkit/macOS 管理员授权、物理切网/休眠和用户真实远端节点未纳入自动化结论。Windows 仍未做发行商代码签名，macOS 仍为 ad-hoc 签名且未公证；Tauri updater 签名与发行商签名分别记录。

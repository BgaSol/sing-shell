# Sing Shell v0.9.0

托盘现在可以选择已导入的服务器，再明确连接或切换。选择服务器不改变当前连接；运行 A 时选择 B，会同时显示实际连接 A 和切换到 B 的操作。连接失败保留选择，断开始终结束当前会话，查看原因才打开主窗口。

节点页区分已选择、使用中和正在连接。选择服务器不再误触发设置待应用；对当前连接应用已保存设置时保持实际节点，也保留另外选择的服务器。原始配置、短期系统授权、一次失败回退和退出清理沿用既有边界，不新增依赖或更改数据格式。

## 验证与限制

发布验证进行中，正式发布前记录固定源码、五原生 Check、真实 TUN、签名原包、实际启动退出和升级结果。

新增自动化覆盖选择持久化、失败保存、修订冲突、恢复依据隔离和托盘状态；实际应用 smoke 检查 2,000 个原生菜单项、勾选、重命名和模式更新。真实网络回归检查选择不打断旧连接、应用设置不顺带切换所选节点。

原生菜单展开中的鼠标、键盘、滚动、交互 UAC/polkit/macOS 管理员授权、物理切网/休眠和用户真实远端节点未纳入自动化结论。Windows 仍未做发行商代码签名，macOS 仍为 ad-hoc 签名且未公证；Tauri updater 签名与发行商签名分别记录。

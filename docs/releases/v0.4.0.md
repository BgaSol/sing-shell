# Sing Shell v0.4.0

关闭窗口现在会收起并保留核心运行和设置草稿。Windows/macOS 提供托盘入口，Linux 保留最小化窗口入口；真正退出统一处理草稿、等待任务并停止核心。

设置页增加两个独立开关：登录后自动启动应用、应用启动时恢复核心运行状态，默认关闭并立即保存。成功运行后记录意图，主动停止会撤销，恢复只尝试一次；重复打开唤回现有窗口。应用更新使用同一退出链路，并保留恢复意图及系统登录登记。

v0.2.0/v0.3.0 可在线升级，旧设置备份后迁移至 schema 3，外部核心保持原选择。Linux DEB 使用系统安装方式，v0.1.0 需手动安装。

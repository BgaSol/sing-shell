# Sing Shell v0.6.1

修复受管核心已有版本目录却显示“尚未安装”，并持续报“已有版本目录内容不一致”、无法更新的问题。首次准备、旧设置显式初始化和中断恢复统一按已验证材料继续，相同程序可复用，有效归档无需重复下载。

“检查核心”只检查版本；更新与重试按失败阶段执行。采用途中取消、设置保存失败及准备记录清理失败分别处理，保留真实选择和一次回退状态，避免后台反复重放同一失败。

## 验证

发行前执行五目标原生检查、签名构建及实际包验收，覆盖 v0.5.4 与 v0.6.0 升级、受管核心恢复、真实官方核心及 TUN 启停。固定源码、运行与摘要报告在验收完成后记录。

## 边界

设置继续使用 schema 5，0.6.0 用户无需重新初始化；旧代格式仍需明确备份初始化。外部核心和原始配置继续由用户维护，授权 worker、应用 updater 和 TUN 权限边界不变。Windows 尚无发行商代码签名，macOS 仍为 ad-hoc 签名、未公证。

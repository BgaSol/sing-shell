# Sing Shell v0.5.3

macOS TUN 改为连接时通过系统管理员授权启动短期 worker，断开后退出。保留同安装、同构建运行代码的双向身份校验与有界握手，不再依赖跨版本 SMAppService 网络服务登记。旧登记仅在确认闲置且属于本应用时撤销。

实机追查确认：ad-hoc 签名更新后，旧登记的启动约束拒绝当前构建，随后失效为 EX_CONFIG；重新允许、刷新应用登记和注销后重新登记均不能可靠恢复。同一程序使用全新登记可启动，但逐版本换服务名不是长期方案。维护者选择按需系统授权，无需 Apple Developer ID 证书。

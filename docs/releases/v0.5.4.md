# Sing Shell v0.5.4

macOS TUN 连接时自动登记临时系统 DNS，解决局域网路由器解析绕过 TUN、节点正常却无法访问域名的问题。断开释放解析器，原有 Wi-Fi／以太网 DNS 偏好保留，无需新增设置。

统一授权进程所有权和 worker 清理，启动失败、取消及异常退出共用资源收尾；补全双栈路由覆盖检查，避免局部路由被误判为连接就绪。页面、托盘和更新交接使用统一会话事实，Windows 安装范围识别归入平台层，保留现有安装及登录项行为。

## 验收状态

正在进行五原生检查、网络集成和实际签名包验收，尚未发布。137 Mac 临时 DNS 原型已验证系统解析恢复、HTTPS 204、正常释放及进程被强杀后的系统回收；这些原型结果不替代最终发行包验收。

设置 schema 保持 4，不改变节点格式、分流语义及外部核心。macOS 仍为 ad-hoc 签名、未公证；实际托盘视觉、注销登录、休眠及物理切网尚未验收。

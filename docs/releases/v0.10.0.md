# Sing Shell v0.10.0

自定义直连规则新增“绕过 TUN”。沿用已有精确域名、IPv4 / IPv6 和网段，勾选、保存并应用重连即可，无需声明程序或手改核心配置。目标按真实 IP 使用系统网络，可改善远程控制和打洞兼容性。

## 行为与边界

域名在连接准备时解析，当前会话固定同一批 DNS 回答和排除地址，地址变化后再次“应用并重连”刷新。解析或配置检查失败保留旧连接；切换失败的一次恢复复用旧连接实际地址。停止、退出和异常清理沿用按需授权 worker，不新增后台服务或生产依赖。

绕过优先于普通分流顺序，作用于整条规则；共享 IP 的其他服务也会绕过。这部分流量不计入活动统计，不受核心 IPv4 兼容模式约束。默认关闭，旧 schema 5 设置直接兼容；代理、开源来源、默认规则和包含子域名的条件不提供绕过。

首版最多 32 个去重精确域名、64 个最终排除地址 / 网段。解析和准备有界，失败不会部分应用或静默退回普通直连。独立 DoH、程序旧缓存、动态对端及其他 VPN 继续服从各自网络行为。

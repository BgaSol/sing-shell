# Sing Shell v0.2.0

新增应用及受管官方 sing-box 的独立更新，默认每日检查，手动下载并明确重启应用。Windows、macOS、Linux AppImage 使用官方 Tauri updater，Linux DEB 继续使用系统安装方式。

软件更新页提供进度、说明、重试/取消、备用下载线路及自定义 HTTPS 地址。外部核心不被覆盖；受管核心核验摘要、原生架构、实际版本和配置后准备，重启时切换。

应用状态、设置、进程监督与退出按职责分离，慢校验和下载不占整应用状态锁。旧设置备份后迁移，原核心作为外部来源保留。普通启动和更新重启后均需手动启动核心。

此版是首个 updater 签名基线，v0.1.0 用户需手动下载安装；安装包仍只包含桌面壳。

## 验证状态

代码已实现，正在执行本次五平台实际包及隔离升级验收。发布前补充原包来源、原始运行、Release、摘要报告和实际验证/跳过范围；当前不宣称发行验收完成。

## 限制

Windows 无发行商代码签名，macOS 未公证；updater 签名不替代这些系统认证。尚未验收互联网下载后的系统提示。无订阅、节点管理、系统代理开关、TUN 提权、托盘或后台服务。

核心停止仍用进程组终止，Unix 宿主被 SIGKILL 时不能保证清理；双组件应用不提供跨组件原子事务。行为与恢复见[软件更新](../features/updates.md)。

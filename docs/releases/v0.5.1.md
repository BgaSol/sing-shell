# Sing Shell v0.5.1

修复带 `encryption=none` 的 VLESS 分享链接导入，保留 TLS、WebSocket Host、路径与独立 SNI；缺省与显式 none 按相同节点去重。整理共享链接解析，严格检查编码、重复与未知参数，拒绝冲突的 TLS 不安全开关。

修复新预览失败后旧票据仍可提交；文件读取和非法 UTF-8 失败会清除旧预览，错误行号保留原始空行。设置 schema、已有节点和受限网络 worker 协议保持兼容。

## 验收与发行来源

本地 Windows x86_64 的类型/格式检查、11 项工程脚本检查和 Rust 测试通过；默认 Rust 测试 92 项通过、4 项真实核心测试明确跳过。另使用官方 sing-box 1.14.4 实际执行包含 ignored 项的 8 项 profile 集成，全部通过，覆盖完整 VLESS + TLS + WebSocket 分享链接生成配置，以及受控加密出口分流。配置通过不代表用户节点实际握手或转发已验证。

包源码固定为 `259ecce53f94c92f35b4d3e5e82b5eb082cbfc8f`，经 [PR #2](https://github.com/BgaSol/sing-shell/pull/2) 合入主分支。该源码的[五原生 Check](https://github.com/BgaSol/sing-shell/actions/runs/45774384755)及[合入后的主分支 Check](https://github.com/BgaSol/sing-shell/actions/runs/45775207398)均通过。

[五原生签名打包和独立实际包验收](https://github.com/BgaSol/sing-shell/actions/runs/45774387070)全部通过。原始 15 个包/签名附件的大小、SHA-256、实际核心和平台、升级及跳过范围见[完整验收证据](v0.5.1-verification.json)。ARM64 使用原生运行器，未用交叉编译代替运行。

实际验证包含官方 sing-box 1.14.4 配置/受控分流、加密 TUN IPv4/IPv6 TCP/UDP 及异常清理、安装后启动退出和签名升级。v0.2.0 / v0.3.0 / v0.4.0 → 本版保留旧设置迁移和外部核心选择；新增 v0.5.0 → 本版与本版 → 隔离 0.5.2 候选的 schema 4 节点保留检查，核对已有 VLESS 凭据、独立 SNI、WebSocket Host/路径、节点选择和分流。更高候选不进入正式发行。

已正式发布为 [Latest](https://github.com/BgaSol/sing-shell/releases/latest)。16 个公开 HTTPS 附件（含更新清单）已在无登录状态逐一下载，大小与 SHA-256 全部匹配；更新清单的五平台 URL、签名和摘要均与验收原包一致。公开下载结果一并保存在完整验收证据中。

## 已知边界

- WebSocket Host 不自动作为 TLS SNI；真实服务器的证书名称要求仍应由链接的 `sni` 表达。
- 非法 URL 编码、非法 UTF-8 文件和冲突的 TLS 别名现在明确拒绝，已有持久化节点不会批量重写。
- Windows 无发行商代码签名；macOS 使用 ad-hoc 签名，未公证。updater 使用独立正式签名。
- UAC/polkit 交互、macOS 用户允许后的 launchd 激活、实际注销登录、物理切网及其他 VPN 共存没有由本次节点解析回归代替验证。

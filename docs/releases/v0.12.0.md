# Sing Shell v0.12.0

统一采用 SoDeck 多巴胺视觉、深色描边和紧凑布局，窗口顶部整合连接状态及控制。节点导入自动预览，规则表单一次保存，出口、启用与顺序自动保存；连续修改后通过顶部统一应用并重连。设置收敛为常规、更新和高级，更新开关与下载网络独立保存，活动分为连接和日志。

保存、导入、模式切换与退出沿完整链路重构：规则与来源偏好原子提交，迟到读取不覆盖写后状态，模式切换完成真实停止后提交。保持 schema 5、已有节点/规则/偏好、外部核心与原始配置，TUN 授权、核心签名及清理边界延续。受控 TUN 仍按需授权，不增加持久后台服务。

## 验证

本地 Windows x86_64 类型/格式、26 项脚本、154 项 Rust 测试通过，9 项需外部核心或原生桌面的默认测试明确跳过；其中官方 sing-box 1.14.4 的协议配置与受控分流两项另行执行通过。NSIS 构建及实际程序 smoke 通过，自绘关闭按钮触发真实收起，退出完成资源收尾。浏览器检查覆盖默认与最小窗口、自动预览、一次保存、失败保留输入、开关回退、未保存确认的快捷键隔离及删除后的焦点恢复。静态设计检测无发现。

五原生 Check、网络及签名原包验收正在执行，最终记录将补充固定源码、结果与跳过范围。本地脚本首次遇到 Windows 临时端口 EACCES，未改断言，重跑通过；新增测试夹具初次目录碰撞已通过独立序号修正。

# Sing Shell v0.12.0

统一采用 SoDeck 多巴胺视觉、深色描边和紧凑布局，窗口顶部整合连接状态及控制。节点导入自动预览，规则表单一次保存，出口、启用与顺序自动保存；连续修改后通过顶部统一应用并重连。设置收敛为常规、更新和高级，更新开关与下载网络独立保存，活动分为连接和日志。

保存、导入、模式切换与退出沿完整链路重构：规则与来源偏好原子提交，迟到读取不覆盖写后状态，模式切换完成真实停止后提交。保持 schema 5、已有节点/规则/偏好、外部核心与原始配置，TUN 授权、核心签名及清理边界延续。受控 TUN 仍按需授权，不增加持久后台服务。

# Sing Shell v0.11.0

分流页面采用清晰列表，每条规则可直接切换代理／直连，自定义直连旁可开关“绕过 TUN”。编辑、上移、下移、移除直接显示；默认规则固定在末尾。移除分类筛选和拖拽，统一全局顺序及行内排序。

编辑已有规则时只修改名称、域名和 IP。绕过开关遇到包含子域名仍可点击，并就地提示修改；一条待修正规则不会阻塞其他规则编辑。整张表保存仍严格校验，失败保留草稿；保存期间冻结修改，后台快照与迟到校验不覆盖输入。保存与应用重连继续分开，来源更新设置保持独立自动保存。

## 验证与限制

本地类型／格式检查、28 项脚本回归、默认 Rust 测试、Windows x64 MSI／NSIS 构建和隔离应用启动／退出已通过。官方 sing-box 1.14.4 的全部协议配置及受控加密出口路由测试、绕过 DNS 固定结果与解析进程回收测试通过。默认 Rust 测试中要求额外官方程序或可丢弃原生环境的项目仍按各自要求跳过，没有当作通过。

真实前端配合隔离 IPC 的浏览器验收覆盖行内切换、字段冲突、其他行独立编辑、新增精确域名、排序／移除／撤销、慢保存冻结、失败保留、修订冲突、保存与应用分离、来源偏好保留及原始配置只读；620×560 规则表单头尾和字段无裁切。浏览器无控制台错误。该结果不代表五平台 WebView 的逐项人工交互已验证。

五原生 Check、网络及签名实际包验收正在执行，尚未正式发布；最终源码、运行记录、摘要及跳过范围在验收后补充。

本版保持已有 IPC、schema 5 和网络流程，不新增生产依赖。绕过按真实 IP 生效、共享 IP、连接时解析及重连刷新等边界保持；未进行用户真实 RustDesk 两端 P2P 验证，不保证任意 NAT 环境下的打洞。

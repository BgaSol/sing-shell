# Sing Shell v0.11.0

分流页面采用清晰列表，每条规则可直接切换代理／直连，自定义直连旁可开关“绕过 TUN”。编辑、上移、下移、移除直接显示；默认规则固定在末尾。移除分类筛选和拖拽，统一全局顺序及行内排序。

编辑已有规则时只修改名称、域名和 IP。绕过开关遇到包含子域名仍可点击，并就地提示修改；一条待修正规则不会阻塞其他规则编辑。整张表保存仍严格校验，失败保留草稿；保存期间冻结修改，后台快照与迟到校验不覆盖输入。保存与应用重连继续分开，来源更新设置保持独立自动保存。

# Sing Shell v0.7.0

节点模式内置 Fake-IP，并增加一个全局“IPv4 兼容模式”。核心先还原域名和真实地址，再保持既有策略顺序分流；遇到 IPv6 TLS 失败可开启兼容模式，保存后应用并重连。仅 IPv6 网站在兼容模式下不可访问，节点服务器入口解析独立。

连接输入、配置编译和 worker 资源边界集中整理。映射按已认证用户保存在受保护本机目录，跨正常重连/换节点复用；断开仍释放 TUN、临时 DNS 和短期 helper。原始配置与外部核心不被改写，不增加自动测速、节点探测或自定义核心。

## 数据与限制

schema 5 的缺省连接设置保持关闭，无需重新导入节点。映射包含访问域名，仅保存本机；缓存删除/损坏、强杀及地址池回绕后的旧地址不保证透明恢复，可能需要重新解析或重启浏览器。独立 DoH/DoT、HTTPS/SVCB 提示及旧真实地址缓存不保证经过 Fake-IP。

Windows 未做发行商代码签名，macOS 使用 ad-hoc 签名且未公证；正式包具有独立 Tauri updater 签名。最终执行范围另附本版验证文件。

原故障节点 `jpwus1`、第二节点和 Mac/Windows 的 Gmail 实际浏览器对照未执行；受控 TLS 夹具不替代真实节点结论。浏览器独立 DoH/ECH、物理切网/休眠、完整池回绕与磁盘增长长跑、交互授权及真实登录/注销同样记为跳过。尚未验证的路径不包含在本版通过结论中。

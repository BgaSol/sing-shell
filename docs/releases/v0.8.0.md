# Sing Shell v0.8.0

修复已下载并校验的核心在首次连接时仍需重新查询 GitHub API、因 403 限流或读取中断而失败的问题。受管核心改为采用 Sing Shell 已验证的官方版本，普通维护先准备项目签名材料和程序；授权 worker 离线验签、复核字节并安装，不再重新发现或下载核心。

保留独立核心更新与短期系统授权，不新增后台服务、第二套核心设置或用户 token。新版本发布可能晚于上游，核心签名表示 Sing Shell 核对官方材料，不能冒充上游原生签名。外部核心、原始配置、节点、分流与 Fake-IP 行为保持原边界。

## 验证与限制

五平台原生、实际安装包、旧设置升级、官方 1.14.4/1.14.5、签名与公开附件的最终执行结果将在本版验证证据中记录。未执行前不视为通过。

核心材料齐全后的受保护安装不依赖核心发行网络；未缓存规则、用户配置远程资源、真实 DNS 和节点连接仍可能需要网络。系统授权、磁盘写入、配置检查仍可能失败。Windows 发行商代码签名、macOS 公证、真实故障节点与人工授权交互未纳入自动化通过结论。

发布前核对 16 个附件的大小、SHA-256 及五目标更新清单、下载地址与签名，均与验收原包一致。正式发布后再次匿名 HTTPS 下载全部 16 个附件，大小和摘要与草稿、验收原包完全一致；最新发行和标签源码均已确认。详细执行范围与首次失败见本版包验证、网络验证文件。

官方 sing-box 1.14.5 的[五原生核心渠道验证](https://github.com/BgaSol/sing-shell/actions/runs/45965884819)通过后，发布独立项目签名的固定版本材料及推荐入口。两份公开材料已经匿名 HTTPS 下载、核对 SHA-256 和内置公钥验签，与应用内置的 1.14.5 材料完全一致。1.14.4 保留为安装引导基线，已有 1.14.5 可直接按内置材料复核，无需退回旧版。

本地 Windows 的类型/格式、20 项脚本测试、137 项默认 Rust 测试、NSIS 构建与应用启动/退出 smoke 通过。真实核心专项另验证两版程序的空目录分块安装、签名与字节核对、同版本资产冲突、等大小篡改、中断暂存清理及已运行 PID/状态保持。没有新增生产依赖，未改变 npm/Cargo 锁文件。测试构建使用独立公开夹具密钥，正式构建只接受生产公钥。

验收工具首次在 Linux 使用 GNU tar 读取 Windows ZIP 失败，改用 libarchive；旧真实核心测试将启动版本写死为 1.14.4，改为读取实际版本；Rust 测试工作目录导致相对材料路径失效，改为显式绝对路径。最终源码前的 Linux ARM64 网络验收一次系统查询返回 ENOTFOUND，核心安装、TUN 和双栈转发已通过；同一运行代码复验及最终源码五平台验收均通过，未放宽 DNS 断言，首次报告保留。两批中间应用包因发布前复核补充同版本身份保护、运行中修复门禁和真实运行状态判断而废弃，均未发布。

六种协议均沿用官方配置校验，受控加密转发使用 Shadowsocks。原用户 Mac 的实际 403、故障节点/浏览器对照、真实 API 额度耗尽、交互授权、物理切网/休眠及长时间 Fake-IP 池回绕未执行；不把自动化夹具视作这些路径已经通过。

核心材料齐全后的受保护安装不依赖核心发行网络；未缓存规则、用户配置远程资源、真实 DNS 和节点连接仍可能需要网络。系统授权、磁盘写入、配置检查仍可能失败。Windows 发行商代码签名、macOS 公证、真实故障节点与人工授权交互未纳入自动化通过结论。

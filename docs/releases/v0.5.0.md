# Sing Shell v0.5.0

新增节点导入与单节点选择、默认 TUN、域名/IP/CIDR 分流和 8 类常用站点。未命中规则默认代理；运行中保存后明确应用并重启，失败恢复上一连接一次。旧配置和外部核心保留，设置迁移至 schema 4。

GUI 保持普通权限；Windows UAC、Linux polkit、macOS 13+ SMAppService helper 按需处理网络。受控 TUN 仅执行独立核验的官方 sing-box 1.14.4–1.14.x。应用、核心及站点规则分别维护。

## 验收与发行来源

正式发布前补入五原生实际包的固定来源、摘要和验证报告；未完成验收时不得把此文档当已发布证据。

## 已知边界

- Windows 未做发行商代码签名；macOS 仅 ad-hoc 签名，未做 Developer ID 与公证。updater 使用独立正式签名。
- 系统权限对话框、macOS 用户允许后的 launchd 激活、实际注销登录、睡眠/物理切网及其他 VPN 共存尚需人工场景验证，自动化结果不替代这些范围。
- 不含订阅自动更新、测速、策略组、系统代理开关或崩溃重连。原始配置模式兼容旧系统，不将任意配置交给管理员进程。

# Sing Shell v0.3.0

新安装自动获取适合本机的官方 sing-box 核心，准备期间可先导入配置。受管核心默认自动检查、下载和验证；运行中保持当前代理，新版停止后或下次启动前生效，无需重启整个应用。

核心来源、配置与启停统一由独立用例协调，加入短暂启动观察、上一版本记录和一次失败回退。旧外部核心选择保留；应用更新仍独立手动下载并明确重启。

## 验证状态

实现与本地回归已进入验收，发布前补充固定源码、五平台原始包、原生实际包与升级运行、Release、摘要和匿名下载证据。当前不宣称发行验收完成。

## 限制

首次准备需要访问官方 GitHub API，官方元数据不可获得时不信任镜像自报摘要。2 秒启动观察只识别明显进程启动失败，不代表网络连通性；普通后期异常退出不自动重启。配置不兼容不自动改写。

Windows 无发行商代码签名，macOS 未公证，互联网下载后的系统提示未全面人工验收。没有系统代理开关、TUN 提权、订阅、节点管理、托盘或后台服务。Unix 宿主被 SIGKILL 时无法执行退出清理。

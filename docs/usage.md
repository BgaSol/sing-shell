# 首次使用

1. 打开 Sing Shell，应用会自动下载并校验适合本机的官方核心，首页显示准备进度。
2. 点击“导入配置”，选择自己的 JSON / JSONC 文件。下载期间可以先选择，核心就绪后再完成校验。
3. 显示核心已就绪、配置通过后，点击“启动 sing-box”，观察状态和日志；点击“停止”结束进程。不会自动启动或因更新打断运行。

可使用 [`examples/direct.json`](../examples/direct.json) 测试：它在 `127.0.0.1:2080` 提供 HTTP / SOCKS5 直连入口，不改变系统代理，也没有远程代理节点。

首次下载失败可重试，或展开首页高级选项“使用本机核心”。已选外部核心继续由用户维护，应用升级不会接管。受管核心默认自动更新，正在运行时只准备新版，下次启动生效；开关、取消、失败回退和应用独立更新见[软件更新](features/updates.md)。

本机核心、配置校验、实际运行状态和限制见[核心与配置](features/core.md)。

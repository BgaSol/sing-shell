# 首次使用

Windows 安装时可选择“所有用户”（默认 Program Files，需要管理员权限）或“当前用户”。已有安装更新保留原范围；切换范围前先退出并卸载旧安装，不勾选删除应用数据，再重新安装。两种安装的界面都以普通用户运行，连接 TUN 时单独授权。

普通账户若要为所有用户安装，请先通过“以管理员身份运行”打开安装器；系统级安装的更新和卸载会按需请求管理员授权。

1. 打开 Sing Shell，等待官方核心准备完成。
2. 到“节点”粘贴分享链接或选择 TXT / JSON / JSONC，预览后确认导入。
3. 选择一个节点，到“运行”启动，按系统提示授权。默认 TUN，未命中规则默认代理。
4. 到“分流”选择直连站点或添加域名、IP/CIDR 规则并保存。运行时修改后，点击“应用并重启”生效。

macOS TUN 需要 13+，先将完整 app 安装到 Applications（应用程序），退出其他位置的旧副本；首次连接需在系统设置 → 通用 → 登录项与扩展中允许 Sing Shell 网络 helper，再重试。Linux 需要 polkit 和图形授权代理。拒绝或清理失败不会反复自动申请。

已有配置的旧用户继续原始配置模式，可在设置切换模式。原始配置引用原文件，由核心校验，不改写路由，仍可使用本机核心。

可使用 [`examples/direct.json`](../examples/direct.json) 测试：它在 `127.0.0.1:2080` 提供 HTTP / SOCKS5 直连入口，不改变系统代理，也没有远程代理节点。

首次下载失败可重试，或展开首页高级选项“使用本机核心”。已选外部核心继续由用户维护，应用升级不会接管。受管核心默认自动更新，正在运行时只准备新版，下次启动生效；开关、取消、失败回退和应用独立更新见[软件更新](features/updates.md)。

本机核心、配置校验、实际运行状态和限制见[核心与配置](features/core.md)。

## 托盘与启动

关闭窗口会收起并保留核心和设置草稿，首次会说明返回入口。Windows/macOS 从托盘返回；Linux 从系统窗口入口返回。设置页可以真正退出应用。

设置 → 启动与窗口两个开关默认关闭、立即保存。恢复只尝试上次成功且未主动停止的连接一次；Windows/Linux 不在登录时静默弹授权，需手动连接。登录项读取系统事实，被禁用时按提示到系统设置允许。停止释放 TUN；真正退出会等待网络清理。

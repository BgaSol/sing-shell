# 首次使用

Windows 安装提供“所有用户”和“当前用户”，更新沿用原范围。GUI 以普通用户运行，TUN 连接按需授权。macOS 先将完整 app 安装到 /Applications 或 ~/Applications；Linux 需要 polkit 和图形授权代理。

1. 打开应用，到节点页点击“导入节点”。官方核心同时在后台准备。
2. 粘贴分享链接或选择 TXT / JSON / JSONC，自动预览有效、重复与错误项，点击“导入 N 个有效节点”。JSONC 需要核心格式化，核心未就绪时等待准备。
3. 点击节点的“连接”，按系统提示授权；默认 TUN、未匹配规则默认代理。切换节点直接点击目标行“切换”，顶部统一断开。
4. 分流页新增域名/IP 规则或固定站点规则。编辑一次保存，出口、启用和顺序自动保存；运行中最后点击顶部“应用并重连”，未连接则下次生效。

需要完整 sing-box 配置时进入设置 → 高级，明确切换原始配置模式。运行中确认“切换”会断开并等待清理；失败不切模式。选择配置后由核心检查，启动前再次检查，文件保持原位。外部核心只用于原始配置，不被更新器覆盖。切回节点模式需已有可验证的受管官方核心，缺失时按提示先断开并准备应用管理核心。

可使用 [直连示例](../examples/direct.json) 测试原始配置，它在 127.0.0.1:2080 提供 HTTP/SOCKS5 入口，不改变系统代理。旧代设置继续保留原件并要求显式备份初始化；现有 schema 5 数据直接保留。

## 托盘与启动

关闭窗口只收起，保留连接、下载与编辑内容。Windows/macOS 从托盘返回，Linux 从系统窗口入口返回。真正退出使用左上角应用菜单或托盘，等待网络释放；有未保存编辑时只作一次保存/放弃/取消决定。

设置 → 常规可开启登录后后台启动；系统禁用或登记异常时就近提示。原始配置的一次运行恢复位于高级设置，默认关闭。节点模式始终等待明确连接和系统授权，不在登录时反复弹框。

## 兼容与排障

设置 → 常规的 IPv4 兼容模式立即保存；已连接时应用并重连后生效。仅 IPv6 网站可能不可访问，节点服务器入口仍独立连接。浏览器独立 DNS 和旧缓存可能需要重新解析或重启浏览器。

自定义直连规则在编辑器开启“绕过 TUN”，使用精确域名和 IP，保存后应用并重连。目标按真实 IP 使用系统网络，共享 IP 的其他服务也可能受影响；域名地址变化后再次应用刷新。此流量不计入活动统计，不保证任意 NAT 下的打洞成功。

活动页分为连接和日志；日志保留本机最近 1,000 条，向上阅读会暂停跟随。设置 → 更新分别展示应用和核心状态；下载网络与线路诊断位于高级设置。更具体边界见[节点](features/nodes.md)、[分流](features/routing.md)、[核心](features/core.md)和[更新](features/updates.md)。

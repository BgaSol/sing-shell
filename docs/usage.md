# 首次使用

Windows 安装时可选择“所有用户”（默认 Program Files，需要管理员权限）或“当前用户”。已有安装更新保留原范围；切换范围前先退出并卸载旧安装，不勾选删除应用数据，再重新安装。两种安装的界面都以普通用户运行，连接 TUN 时单独授权。

普通账户若要为所有用户安装，请先通过“以管理员身份运行”打开安装器；系统级安装的更新和卸载会按需请求管理员授权。

1. 打开 Sing Shell，等待官方核心准备完成。
2. 到“节点”点击“导入节点”，在弹窗粘贴分享链接或选择 TXT / JSON / JSONC，预览后确认。
3. 点击对应节点的播放按钮，按系统提示授权。默认 TUN，未命中规则默认代理。
4. 到“分流”创建包含多个域名/IP 的规则或添加固定开源规则，调整顺序并保存。运行时点击“应用并重连”采用。

macOS 先将完整 app 安装到 /Applications 或 ~/Applications，每次连接通过系统管理员授权弹窗启动短期 worker，不登记持久后台网络服务。Linux 需要 polkit 和图形授权代理。拒绝或清理失败不会反复自动申请。

0.6 使用新设置格式，旧代设置不迁移或覆盖；原件保留并停止自动恢复。确认“备份并重新初始化”后重新导入节点和规则。原始配置文件、外部核心文件不删除；需要完整配置时，在“设置 → 高级”明确切换原始配置模式，停止后导入原文件。

可使用 [`examples/direct.json`](../examples/direct.json) 测试：它在 `127.0.0.1:2080` 提供 HTTP / SOCKS5 直连入口，不改变系统代理，也没有远程代理节点。

首次下载失败可重试，或在“设置 → 核心与更新”选择本机核心用于原始配置。已选外部核心继续由用户维护，应用升级不会接管。受管核心默认自动更新，正在运行时只准备新版，下次启动生效；开关、取消、失败回退和应用独立更新见[软件更新](features/updates.md)。

本机核心、配置校验、实际运行状态和限制见[核心与配置](features/core.md)。

## 托盘与启动

关闭窗口会收起并保留核心和设置草稿，首次会说明返回入口。Windows/macOS 从托盘返回；Linux 从系统窗口入口返回。设置页可以真正退出应用。

设置 → 通用两个开关默认关闭、立即保存。恢复只尝试上次成功且未主动停止的连接一次；Windows/Linux 不在登录时静默弹授权，需手动连接。登录项读取系统事实，被禁用时按提示到系统设置允许。停止释放 TUN；真正退出会等待网络清理。

## 部分网站在 IPv6 下打不开

节点模式已内置 Fake-IP。若仍出现部分网站连接关闭，进入“设置 → 网络”，开启“IPv4 兼容模式”并保存；已连接时点击顶部“应用并重连”。仅 IPv6 网站在开启时不可访问，需要时关闭并重连。节点服务器自身入口仍独立连接。

浏览器独立 DNS 或旧地址缓存可能不经过 Fake-IP；应用重连后仍失败可重新打开页面，必要时重启浏览器，再换节点对照。该开关不判断节点 IPv6 能力，也不修改系统网卡 IPv6。

## 远程控制和打洞兼容

在“分流”编辑对应的自定义直连规则，勾选“绕过 TUN”，完成并保存；已连接时点击“应用并重连”。沿用现有精确域名和 IP，无需指定 RustDesk 程序。域名若设置为包含子域名，先改为精确匹配。

目标按真实 IP 使用系统网络，优先于其他分流规则，共享 IP 的其他服务也会受影响。域名地址变化后再次应用并重连；必要时重启目标程序以刷新旧缓存。绕过流量不计入活动统计，也不受核心 IPv4 兼容模式约束。动态对端未包含在这些地址中时仍按普通 TUN 处理，实际打洞结果仍取决于 NAT、防火墙和远端网络。
